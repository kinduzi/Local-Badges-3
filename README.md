# LocalBadges

Client-sided custom badges plugin for **Revenge / Bunny / Kettu / Vendetta**.

Only **you** can see the badges you add.

## Install Link

After you host this on GitHub Pages, the install link will be:

```
https://YOUR_USERNAME.github.io/YOUR_REPO/LocalBadges/
```

## How to use

1. Install the plugin using the link above.
2. Open **Settings → Plugins → LocalBadges → Settings** (gear icon).
3. Enter a User ID + Image URL + optional tooltip.
4. Press **Add Badge**.

## Important Notes

- The badge injection into profiles still needs to be finished (the component Discord uses changes often).
- This template gives you the full settings UI and storage system ready to use.
- You will need to update the patching code after Discord updates.

## Development

Replace `YOUR_DISCORD_ID_HERE` in `manifest.json` with your real Discord user ID.
